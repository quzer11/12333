# 郭智淳 · 主角登场

粉色海报风的个人展示网页，含约四秒的舞台出场动画和三张 AI 创意海报。

## 使用

直接用浏览器打开 `index.html` 或 `沪深股票1443.html`。两者内容相同，保留文件名供课堂提交。
下载整个仓库后打开时，请保留 `assets` 文件夹。

也可在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 功能

- 全屏幕布、聚光灯、姓名出场和彩纸；支持跳过、Escape 和自动结束。
- 排面调节器与暂停特效；遵循系统“减少动态效果”设置。
- 舞台大片、霓虹未来、漫画封面三张海报；支持放大查看和下载。
- 手机和桌面布局，无第三方脚本、字体或联网依赖。

## 文件

- `index.html`：网站首页。
- `沪深股票1443.html`：同一页面，使用指定中文文件名。
- `assets/portrait.jpg`：用户提供的原照片。
- `assets/poster-*.png`：三张生成海报。
- `创作与使用说明.txt`：操作说明、生成方式和完整提示词。

三张海报为基于用户提供照片生成的 AI 创意画面，不表示真实拍摄场景。
